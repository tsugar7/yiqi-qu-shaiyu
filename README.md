# 一起去“晒”鱼

左滩村六站游玩手帖，基于已确认的 V8 页面整理的静态游客端正式版 1.0。

## 使用

直接以静态网站托管；支持 GitHub Pages 项目子路径。通过 `python -m http.server 8000` 可本地预览。六站扫码链接分别使用 `#entrance`、`#graffiti`、`#fish`、`#animals`、`#plants`、`#hang`。

## 发布

仓库设置 Settings → Pages → Source 选择 GitHub Actions，推送 main 自动发布。

## 功能范围

包含六站路线、地图、故事阅读、三处鱼牌自报领取、挂鱼确认、可选书写提示与本届回顾入口。记录和文字草稿仅保存在当前浏览器；暂未接入组织者后台、在线投稿与统计同步。回顾照片和精选故事需活动后编辑发布。切换设备或网站域名不会自动同步记录。

## 素材

场景和图标来自项目提供素材及授权生成的插画；原始图片嵌入独立 SVG。字体许可保留在 assets 中。仓库不包含原始访谈、个人资料或工作区数据库。
